02 · Domain

Research Domain

Exploring the intersection of computer vision, machine learning, and robotics to automate the centuries-old craft of gemstone cutting for Sri Lanka's gem industry.

Literature Survey
Prior Work & Context

Reviewed 60+ papers on gem classification (CNN/SVM approaches), robotic manipulation (ROS-based systems), defect detection in materials science, and GIA cutting standards. Sri Lanka's gem industry processes over 90% of the world's blue sapphires, yet cutting remains entirely manual.

Research Gap
What's Missing

No existing system integrates gemstone identification, defect evaluation, cut recommendation, and robotic execution in one unified pipeline — especially for Sri Lankan gem types such as Blue Sapphire, Spinel, and Moonstone.

Research Problem
Core Challenge

Traditional gem cutting is expert-dependent, inconsistent, and non-scalable. Sri Lanka's gem industry needs intelligent automation that maintains quality while reducing material waste and cutting time.

Methodology
Our Approach

Multimodal fusion (EfficientNetB3 + physical constants), ensemble defect classifiers, two-stage CatBoost/XGBoost cut planning, and ROS 2 robotic execution via D–H kinematic modelling through a complete integrated pipeline.

Research Objectives

Four Key Goals

  • IDevelop a multimodal gemstone identification system fusing EfficientNetB3 visual features with physical constants (RI, SG, Hardness) across 34 Sri Lankan gem types.
  • IIBuild a defect-aware evaluation module using a Soft Voting Ensemble Classifier with 168-dimensional handcrafted features across 8 defect categories.
  • IIIDesign a two-stage CatBoost/XGBoost cut-type recommendation pipeline predicting crown, pavilion, table, and depth parameters aligned with GIA standards.
  • IVImplement a ROS 2-based robotic execution framework with Gazebo simulation, MoveIt 2 planning, and Sim-to-Real translation via ESP32-S3 and PCA9685.

02b · System Modules

Four Integrated Components

Each module feeds into the next — from gem identification to robotic execution — completing a full pipeline in ~3.2 seconds per gemstone.

MODULE 01
Robotic Arm Control

5-DOF physical prototype with MG996R servos, ESP32-S3, and Raspberry Pi 5 running ROS 2 Jazzy. 6-DOF Gazebo/MoveIt 2 simulation validated for collision-free trajectory planning using D–H kinematics.

±0.4 mm precision
manipulator_phyisical ↗
MODULE 02
Gem Identification

EfficientNetB3 visual features fused with RI, SG, and Mohs hardness constants. Trained on 10,000 samples across 34 Sri Lankan gem types — natural, treated, synthetic, and imitation stones.

92% accuracy
MODULE 03
Gem Evaluation

Soft Voting Ensemble (Random Forest, Extra Trees, Gradient Boosting, SVM) for 8-class defect detection using 168-dimensional handcrafted features. HX711 load cell for weight measurement and value estimation.

F1 = 0.88 ± 0.013
MODULE 04
Cut Recommendation

CatBoost predicts cut family (Brilliant, Step, Mixed, Cabochon). XGBoost selects the precise cut type (Round, Oval, Pear, Marquise…). Regression models output crown angle, pavilion, table %, and depth % for the robotic arm.

84% cut accuracy
