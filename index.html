02 · Research Domain

The Problem We're Solving

Sri Lanka processes over 90% of the world's blue sapphires, yet every cut is made by hand. We're changing that — with intelligent, precision-guided robotics.

Literature Survey
What Came Before

Reviewed 60+ papers spanning CNN/SVM gem classification, ROS-based robotic manipulation, defect detection from materials science, and GIA cutting standards. Prior systems address isolated components — none unify them for Sri Lankan gems.

References:
  1. LeCun et al., 2015 – Deep Learning for Image Recognition
  2. Quigley et al., 2009 – ROS: Robot Operating System
  3. GIA Gemstone Cutting Standards, 2020
  4. Support Vector Machines in Material Classification – IEEE Papers
Research Gap
The Missing Link

No existing system integrates identification, defect evaluation, cut recommendation, and robotic execution in one unified pipeline — especially for species native to Sri Lanka: Blue Sapphire, Spinel, Moonstone, Alexandrite.

Research Problem
Manual Cutting is Unsustainable

Expert-dependent, inconsistent, non-scalable. A master cutter evaluates by eye alone — leading to material waste of 30–70% per stone. Our system targets sub-millimetre precision and data-driven cut planning.

Methodology
Our Approach

Multimodal fusion (EfficientNetB3 + physical constants), soft-voting ensemble defect classifiers with 168-dimensional features, two-stage CatBoost/XGBoost cut planning aligned to GIA standards, and ROS 2 execution via D–H kinematics.

Four Research Objectives

Key Goals

I
Multimodal Gem Identification
Fuse EfficientNetB3 visual embeddings with physical constants (RI, SG, Mohs hardness) across 34 Sri Lankan gem types — natural, treated, synthetic, and imitation.
II
Defect-Aware Evaluation
Soft Voting Ensemble with 168-dimensional handcrafted features for 8-class defect detection. HX711 load cell integration for weight and value estimation.
III
Cut Recommendation Pipeline
Two-stage CatBoost/XGBoost pipeline predicting cut family, precise cut type, crown/pavilion angles, table % and depth % aligned with GIA standards.
IV
ROS 2 Robotic Execution
Gazebo Harmonic simulation, MoveIt 2 trajectory planning, and Sim-to-Real translation via ESP32-S3 and PCA9685 servo driver on a 5-DOF physical prototype.

03 · System Modules

Four Integrated Components

Each module feeds intelligently into the next — from photographic identification through to physical robotic execution — completing a full pipeline in ~3.2 seconds per gemstone.

Module 01 · Robotic Arm Control
Robotic Arm Control

5-DOF physical prototype with MG996R servos, ESP32-S3 microcontroller, and Raspberry Pi 5 running ROS 2 Jazzy. 6-DOF Gazebo Harmonic simulation validated for collision-free trajectory planning using Denavit–Hartenberg kinematic modelling and MoveIt 2.

±0.4 mm precision
manipulator-hardware ↗ manipulator-sim ↗
Module 02 · Gem Identification
Gem Identification

EfficientNetB3 visual features fused with refractive index, specific gravity, and Mohs hardness via late-fusion MLP. Trained on 10,000 samples across 34 Sri Lankan gem types — natural, heat-treated, synthetic, and imitation stones classified simultaneously.

92% accuracy
Module 03 · Gem Evaluation
Gem Evaluation

Soft Voting Ensemble (Random Forest, Extra Trees, Gradient Boosting, SVM) for 8-class defect detection using 168-dimensional handcrafted features — LBP textures, Gabor filters, HOG descriptors. HX711 load cell integration for carat weight measurement.

F1 = 0.88 ± 0.013
Module 04 · Cut Recommendation
Cut Recommendation

CatBoost classifier predicts cut family (Brilliant / Step / Mixed / Cabochon). XGBoost selects precise cut type (Round, Oval, Pear, Marquise, Emerald Cut…). Gradient Boosting regression outputs exact crown angle, pavilion depth, table %, and depth % fed to the robotic arm.

84% cut family accuracy

04 · Processing Pipeline

End-to-End Flow

From raw gemstone placed on the sensor stage to completed robotic cut — the entire pipeline executes in approximately 3.2 seconds.

STEP 01
Gem Placement

Stone placed on load cell + imaging stage. Carat weight recorded via HX711.

~0.2s
STEP 02
Image Capture

Multi-angle photos via camera module. Lighting normalised by diffuse enclosure.

~0.3s
STEP 03
Identification

EfficientNetB3 + physical constants fusion. 34-class prediction with confidence.

~0.6s
STEP 04
Defect Eval

168-feature extraction + Soft Voting Ensemble. 8-class defect classification.

~0.5s
STEP 05
Cut Planning

CatBoost family → XGBoost type → Regression outputs exact cut parameters.

~0.4s
STEP 06
Path Generation

MoveIt 2 plans collision-free trajectory. D–H IK solves joint angles.

~0.7s
STEP 07
Execution

ESP32-S3 drives PCA9685 servo commands. Physical cut performed.

~0.5s
Total Pipeline Latency
~3.2s
